# Rock Paper Scissors Minus One

"Rock Paper Scissors Minus One" is a round-based rock-paper-scissors game built on MacOS with **Godot 4 Mono (C#)**.
Players compete against AI bots, with score tracking, sound effects, and music.

This is my high school Capstone project that I worked on from March to May 2025. The core game mechanics are complete. However, the graphics and the main scene sound effect are not yet fully polished/complete.

---

## Features

- Round-based gameplay with bot opponents
- Score tracking and win/lose logic
- Background music and sound effects
- Built using Godot 4 Mono (C#) on MacOS

---

## Requirements

- Godot Engine **4.4.x or 4.5.1 Mono version (recommended)**
- .NET 6 SDK (for C# support)
- Optional: IDE for C# development (Visual Studio, VS Code, Rider)

---

## How to Run

1. **Clone the repository**
    - Press the green "Code" button on GitHub.
    - Copy the link for the corresponding Git remote access method (or cloning method)
    - Clone the repository in the terminal.

2. **Download Godot Mono**
    - Go to https://godotengine.org/
    - Press "Download Latest" or install a previous version.
    - Important: make sure to install the .NET version with C# support. Otherwise, the game will not run.

3. **Open the project**
    - Open project.godot from the cloned folder.
    - If you are using the latest version (4.5.1), a warning window will show up.
    - Press "OK". This will open the project and change it to a 4.5.1 version.

4. **Run the game**
    - Double click the "Main" tab in the Scene window in the Godot Editor.
    - Run the project by clicking the "Run Current Scene" button on the top right corner.

## Exporting the Game

- Go to Project > Export.
- If an export template has not been set up yet, press "Manage Export Templates".
- Press "Download and Install".
- After an export template is set up, export to your target platform by pressing "Export Project...".
